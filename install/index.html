Install AKS Programming Language

Get up and running with the AKS compiler, language server, and tools in seconds.

Windows Installation

Choose from the native GUI standalone installer or the automated PowerShell script:

Download Native Windows GUI Installer (.exe)

Or install via PowerShell:

iwr -useb https://raw.githubusercontent.com/Anoop-Kumar-Sharma/aks-lang/main/install.ps1 | iex

Linux & macOS Installation

Install via the official POSIX installation script:

curl -fsSL https://raw.githubusercontent.com/Anoop-Kumar-Sharma/aks-lang/main/install.sh | bash

Verify Installation

aks --version
aks new my_project
cd my_project
aks run src/main.aks

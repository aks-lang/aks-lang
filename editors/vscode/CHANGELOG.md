# Changelog

All notable changes to the "aks-lang" extension will be documented in this file.

## [1.0.0] - 2026-09-10

### Added
- Initial release of the official AKS language extension.
- Complete TextMate syntax highlighting for AKS language constructs.
- Language configuration with auto-closing pairs, brackets, and comment support.
- Native Language Server Protocol (LSP) client connecting to `aksls`.
- Debug Adapter Protocol (DAP) integration connecting to `aks dap`.
- Productivity snippets for functions, structs, async tasks, regions, effects, and tests.
- One-click commands to run files, format code with `aksfmt`, and restart the language server.
